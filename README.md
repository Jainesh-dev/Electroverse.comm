

# ⚡ **Electroverse.comm – Official Technical Committee Website**

A futuristic, high-performance web experience showcasing **events, innovation, team, and community initiatives** by Electroverse — the official technical committee powering the culture of technology, creativity, and collaboration.

Built with **React + TypeScript + TailwindCSS**, the website delivers a sleek, neon-themed UI with smooth animations, dynamic timelines, responsive layouts, and an overall premium experience.

## ✨ **Features**

### 🔮 **Futuristic UI**

* Black-Panther inspired theme
* Neon glows, gradients, animated backgrounds
* Built for a modern tech-community vibe

### 🧭 **Smooth Navigation**

* Auto-highlighting navigation
* Scroll-to-section logic
* Seamless mobile + desktop experience

### 📅 **Dynamic Events System**

* Upcoming & past events
* Hover animations
* Event details page
* Full interactive Timeline (2022 → 2026)

### 👥 **Team & Community Focus**

* Committee introduction
* Structured roles
* Animated feature cards
* Photos & dynamic components

## 🛠️ **Installation & Setup**

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/Electroverse.git
cd Electroverse
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start the development server

```bash
npm run dev
```

Website runs at:
👉 `http://localhost:5173/`
